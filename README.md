# Connect — стартовый интерфейс

Независимый личный мессенджер. Первая версия — визуальный каркас на Next.js с тремя разделами: чаты, контакты, настройки. Переключение темы работает локально.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Важно

Это **не работающий мессенджер**: пока нет регистрации, базы данных, отправки сообщений, звонков, push-уведомлений и PWA/APK. Следующий этап — Supabase Auth с приглашениями и защищённая схема данных (RLS).

Никогда не размещайте пароли, сервисные ключи и данные переписок в публичном репозитории.
