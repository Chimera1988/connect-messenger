# Connect — «Если скучно»: пиксельный Соник

Готовая мини-игра в настройках Connect. Никаких правок в `page.tsx`, Supabase, звонках или Android.

## Установка (ровно два файла)

1. `app/layout.tsx` — **заменить** существующий файл в GitHub.
2. `components/ConnectSonicRunner.tsx` — **добавить** новый файл в GitHub.

Сохранить изменения в ветку `main`. После успешной сборки Vercel открыть PWA и перейти в **Настройки → Если скучно**.

## Игра

- Пиксельный Соник бежит по зелёным холмам.
- Роботы-препятствия: Мотобаг (Motobug), Крабмит (Crabmeat), Базз Бомбер (Buzz Bomber).
- Касание игрового поля, кнопка «Прыжок», на клавиатуре пробел/↑.
- Золотые кольца добавляют очки; скорость постепенно увеличивается.
- Рекорд сохраняется на текущем устройстве, без отправки на сервер.
- Работает в тёмной и светлой теме и использует выбранный акцент Connect для кнопок.

Вся графика игры нарисована прямо в компоненте: дополнительных картинок, аудиофайлов и библиотек нет. Файлы игры не требуют доступа к микрофону, камере и контактам.

**Офлайн:** игра не обращается к интернету во время игры, но для запуска PWA с нуля без сети Connect пока нужен отдельно настроенный офлайн-кэш приложения.

## Проверка

1. Перейти в Настройки — там должен появиться «Если скучно».
2. Запустить, перепрыгнуть препятствие, собрать кольцо, проверить рекорд.
3. Закрыть игру и проверить чаты, уведомления, звонки.
4. При повторном открытии игры рекорд должен сохраниться.

Синтаксис TSX и типы игрового компонента проверены локально. Полную сборку Next.js, а также запуск в iPhone PWA здесь проверить не удалось.
