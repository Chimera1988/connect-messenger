# Connect — «Если скучно»: визуал + воздушные препятствия

Установка: **заменить только `components/ConnectSonicRunner.tsx`** в GitHub. Остальные файлы не менять. После публикации обновить PWA.

Исправления:
- Пункт «Если скучно» оформлен самостоятельной **скруглённой стеклянной карточкой**, отделённой от «О приложении» как другие группы настроек. Рамка, подсветка и прозрачность согласованы с палитрой Connect.
- В игре два вида воздушных препятствий Buzz Bomber: низко летящего нужно перепрыгивать; под высоко летящим можно пробежать, но прыгать на него нельзя. Высокие появляются примерно после 10 секунд игры.
- Мотобаг и Крабмит остаются наземными. Кольца, очки, рекорд и механика прыжка не изменены.
- Рисунок и хитбокс воздушных препятствий используют одну высоту, поэтому враги больше не «прилипают» к земле логически.

Требуется тест на реальном iPhone после установки; полная сборка Next.js не запускалась.
