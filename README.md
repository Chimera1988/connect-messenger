# Connect — восстановление аудиозвонков и вызовы из вкладки «Звонки»

## Установка
Заменить в репозитории `Chimera1988/connect-messenger` **ровно 2 файла**:

1. `components/ConnectAudioCalls.tsx` — обновлённая логика звонков.
2. `components/ConnectCallsHub.tsx` — история звонков, вызов из вкладки.

Загрузите файлы в те же папки в GitHub с заменой старых. **Не нужно менять** `app/page.tsx`, `app/layout.tsx`, `public/sw.js`, Supabase SQL, настройки Vercel, Android-проект или APK.

## Изменения
- При открытой PWA входящие звонки проверяются по серверу дополнительно к Supabase Realtime (примерно раз в 2,4 с); после нажатия на push и возвращения в приложение проверка выполняется сразу. Если событие Realtime потеряно, звонок может появиться после следующей проверки.
- Серверные обновления статуса (принятие, завершение) и WebRTC ICE-кандидаты дополнительно синхронизируются с сервером, даже когда WebSocket пропустил событие.
- Запрос доступа к микрофону запускается до сетевого получения ICE/TURN конфигурации, чтобы уменьшить задержки на iPhone.
- Исходящий вызов напрямую уведомляет серверный push-обработчик; резервная отправка из вкладки «Звонки» остаётся, сервер исключает дублирование по ID вызова.
- Во вкладке «Звонки» появляется кнопка новой трубки: выбираете контакт, начинается вызов. Рядом с записью звонка есть отдельная кнопка повторного вызова.
- Передача для нового вызова идёт по ID реальной переписки и ID пользователя, а не по совпадению отображаемых имён.
- Действующие списки контактов, сообщения, история вызовов и уведомления остаются без изменений.

## Проверить после обновления Vercel
1. **iPhone PWA открыта:** Android вызывает iPhone — экран входящего звонка должен появиться; принять, услышать звук в обе стороны, завершить.
2. **Обратное направление:** iPhone звонит Android.
3. **Из вкладки «Звонки»:** нажать новую трубку, выбрать контакт, позвонить; затем проверить повторный вызов из истории.
4. **iPhone PWA закрыта:** дождаться push, нажать уведомление в течение ~50 секунд. Принять активный вызов после открытия PWA. При более позднем открытии звонок уже может завершиться.
5. Проверить mute, завершение, журнал вызовов и сообщения.

## Ограничения
- Фоновый Web Push на iPhone **не равен нативному CallKit** и не гарантирует дозвон при закрытой PWA; требуется открыть приложение для соединения.
- Для некоторых сочетаний сетей нужен TURN-сервер (`CONNECT_TURN_URLS` / `CONNECT_TURN_SHARED_SECRET`). Если звонок принимается, но звук не соединяется, это нужно проверять отдельно.
- Выполнены проверка синтаксиса TSX и тест типов на локальных заглушках React/Supabase. Полная сборка Next.js и реальные звонки на двух устройствах **не были выполнены**; вывод «исправлено на устройствах» можно делать только после теста.
