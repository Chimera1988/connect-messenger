# Connect PWA — история аудиозвонков и push при закрытом приложении

**Установка:** загрузить содержимое этого архива в существующий репозиторий `Chimera1988/connect-messenger`, сохранив папки и имена файлов. Никаких ручных вставок в `page.tsx`, GitHub Actions и APK.

Файлы:

- `app/layout.tsx` — **заменить**: подключает компонент истории вызовов.
- `components/ConnectCallsHub.tsx` — **добавить**: вкладка «Звонки», история всех входящих/исходящих/пропущенных, даты, время и длительность. Также отправляет серверу уведомление о новом исходящем вызове.
- `components/ConnectNotificationSettings.tsx` — **заменить**: запрос разрешения Web Push выполняется непосредственно по нажатию на iPhone.
- `app/api/push/call/route.ts` — **добавить**: проверяет авторизацию вызывающего, права участников, настройки получателя и отправляет безопасное Web Push уведомление.
- `public/sw.js` — **заменить**: показывает push о входящем звонке, не ломая push о сообщениях, и открывает PWA по нажатию.

**Supabase:** создана вспомогательная таблица `public.connect_call_push_log` с RLS и правами только для service role. Существующие `connect_calls` и переписки не изменены. Повторно выполнять SQL не нужно.

**Vercel:** настройки VAPID и Supabase уже обнаружены в существующем проекте. Новые переменные добавлять не требуется.

**На iPhone получателя:**
1. Открыть Connect, установленный на экран «Домой», дождаться обновления PWA.
2. Настройки → Уведомления → включить уведомления и нажать «Подключить уведомления».
3. Разрешить уведомления в системном запросе. В настройках iOS проверить, что у Connect разрешены уведомления.
4. Закрыть PWA (перейти на главный экран), позвонить с другого аккаунта и проверить обычное push-уведомление. По нажатию открывается Connect для принятия звонка, если он ещё активен.

**Ограничения:** обычная iOS PWA не получает нативный экран входящего вызова CallKit или постоянный рингтон при закрытии. Звук уведомления определяется настройками iOS. Доставка Web Push не гарантируется мгновенной; при плохой сети звонок может завершиться до открытия PWA.

**Проверено до установки:** синтаксис TypeScript/TSX и `sw.js`; обработчики push и нажатия на уведомление в тестовой среде; Supabase RLS и права новой таблицы. **Полная сборка Next.js и доставка реального push на iPhone ещё не проверены.**
