# Connect PWA — звуки аудиозвонков

## Установка
Заменить в GitHub **только один готовый файл**:
`components/ConnectAudioCalls.tsx`.

## Добавлено
- При входящем вызове, когда PWA открыта: оригинальная повторяющаяся мелодия из трёх нот.
- У звонящего в фазе ожидания: повторяющиеся гудки.
- При подтверждённом WebRTC-соединении: короткий двухнотный сигнал.
- Сигналы прекращаются при переходе в другой статус или завершении вызова.

## Не изменено
- Логика Supabase, ICE, WebRTC, push, вкладка истории звонков.
- Вызов `getUserMedia()` остался только при начале/принятии звонка.
- Android APK не требуется пересобирать.

## Особенность iPhone
Safari ограничивает автоматическое воспроизведение аудио без действия пользователя.
Входящая мелодия может не прозвучать, пока iOS не разрешит проигрывание.
Если PWA закрыта, используется **системный звук push-уведомления**, а не мелодия приложения.

## Проверка
1. Запустить вызов: у звонящего слышны гудки.
2. На другом телефоне открыть PWA: звучит мелодия входящего вызова, если разрешено браузером.
3. Принять звонок: мелодия/гудки замолкают; когда WebRTC соединён, звучит короткий сигнал.
4. Повторить вызов и завершить: звук не должен оставаться.

Выполнена проверка синтаксиса TypeScript/TSX. Реальное воспроизведение на iOS и подключение
двух телефонов должны быть проверены после публикации.
